# Vos photos de réalisations

Déposez ici les photos de vos créations (format `.jpg`, `.webp` ou `.png`).

Ensuite, remplacez les liens `image` dans `src/data/portfolio.js` par exemple par :

```js
image: '/photos/nom-de-votre-photo.jpg'
```

Les photos de démonstration actuellement affichées sont des images temporaires servant à la mise en page.
